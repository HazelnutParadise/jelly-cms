執行方式Docker 容器自動偵測映像 ghcr.io/hazelnutparadise/jelly-cms:0.9.3 · 由 /.dockerenv 判定
這台是容器，更新要換映像

容器裡換掉執行檔，重建容器就不見了，所以這裡不提供「更新」按鈕。請用你部署的方式把映像換成 0.9.4，啟動時會自動跑遷移。先備份資料庫。

DockerDocker ComposeKubernetesZeabur / Railway
$ docker pull ghcr.io/hazelnutparadise/jelly-cms:0.9.4
$ docker stop jelly && docker rm jelly
$ docker run -d --name jelly --env-file .env -v jelly-data:/data -p 8080:8080 ghcr.io/hazelnutparadise/jelly-cms:0.9.4
用 latest 標籤的話，只要 pull 再重建就好，但建議鎖版本號，才知道自己跑的是什麼。
