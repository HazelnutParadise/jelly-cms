# 01 — 管理者可以可靠安裝與啟動網站

Epic：基礎營運
User Story：從空白環境完成安裝，失敗可安全重試，完成後不重啟即可使用。
Blocked by：無

## 流程與驗收

- [ ] 測試資料庫連線成功或失敗都不改動使用中的連線，並釋放臨時資源。
- [ ] 無效帳號、信箱、站名、密碼或資料庫參數在任何持久化前被拒絕。
- [ ] 空值、空白、超過密碼長度上限與連線錯誤不造成半安裝。
- [ ] 設定使用原子替換與 0600 權限，失敗保留原設定。
- [ ] 建立管理者與網站設定是一致交易，錯誤不能忽略。
- [ ] 重複或並行安裝不能重設既有網站。
- [ ] 已安裝網站拒絕匿名測試任意資料庫連線。
- [ ] 安裝完成後登入、主題、外掛與金流初始化可用，重啟維持一致。
- [ ] 安裝畫面顯示可理解的錯誤，重複點擊不重複提交，不洩漏敏感資料。

## 錯誤歸屬

輸入錯誤由安裝服務回報並由 HTTP 回傳 400；已安裝回傳 409 或 403；資料庫／檔案故障回報一般錯誤，不把密碼、DSN 或內部路徑傳給瀏覽器。測試連線與實際安裝隔離。所有邊界由本工作單負責。

基線 go test ./... 可編譯，但所有套件均無測試。先建立可重現的失敗測試，再指派修正。PostgreSQL 與瀏覽器流程另驗。
