# 42 — 儀表板小工具可自訂，外掛可以擴充後台

User Story：管理者可以在儀表板新增、拖曳、縮放、移除小工具，桌面與手機版面分開儲存；外掛可以提供小工具、後台列表欄位與操作、管理頁分頁、編輯器區塊與認證方式。
Blocked by：無。

## 背景

工單 38 核對時，`web/admin/index.html` 沒有小工具機制。`internal/ext/ext.go` 目前的擴充點是附件儲存、搜尋、留言、通知器、內容後處理、head／footer 注入與媒體處理，沒有上面列的五種。

## 驗收

- 小工具的增刪、拖曳、縮放在重新整理後保留，桌面與手機各自一份。
- 每個新擴充點至少有一個測試外掛實際接上。
