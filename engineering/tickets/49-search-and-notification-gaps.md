# 49 — 搜尋改用 PostgreSQL 全文搜尋，補齊通知事件

User Story：訪客搜尋時得到依相關度排序的結果，商品也搜得到；成員能收到備份結果與排程發布的通知。
Blocked by：無。

## 背景

工單 38 核對時，內建搜尋以 `strpos` 比對正規化文字欄位（見決策紀錄 0008），不是 PostgreSQL 全文搜尋，商品是否在索引內沒有確認。`internal/notify/event.go` 沒有備份結果與排程發布兩種事件，排程發布本身只靠 `published_at` 晚於現在時不公開。

## 要做的事

- 先決定要改成全文搜尋，還是把架構文件的「全文搜尋」改成現行做法。改的話另寫決策紀錄，取代 0008 中不再成立的部分。
- 補兩種通知事件。

## 驗收

- 搜尋方式與架構文件一致。
- 備份完成或失敗、排程文章到時發布，各自送出通知。
