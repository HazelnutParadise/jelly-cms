# 0007 — 已發布的自訂元件版本不可改寫，由資料庫強制

**Status:** accepted
**Date:** 2026-10-24

## Context

管理員可以建立自訂元件（HTML／CSS／JS 單檔加參數宣告），頁面以版本網址嵌入。已發布頁面引用的是元件的特定版本網址，HTML 匯出也要放入精確的發布版本。

## Decision

元件以 `widgets` 加 `widget_versions` 兩層保存，版本以 `(widget_id, version)` 識別。已發布版本由資料庫 trigger 拒絕改寫原始碼、參數、版本識別，也拒絕撤回發布與刪除。元件登錄只做軟刪除，保留版本歷史與已發布頁面的版本網址。

## Options rejected

原始紀錄沒有記下比較過的其他做法。

## Consequences

修改元件一定產生新版本，舊頁面維持原版本。即使應用程式有錯，也無法透過 SQL 改掉已發布版本。版本資料只增不減，佔用空間會持續增加。
