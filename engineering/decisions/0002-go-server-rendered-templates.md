# 0002 — 沿用 Go 伺服器與伺服器端模板

**Status:** accepted
**Date:** 2026-10-22

## Context

專案接手時已經是 Go（Echo、GORM、PostgreSQL）加伺服器端 HTML 模板的單一執行檔：前台主題與後台頁面都由伺服器渲染，後台頁面再用少量原生 JavaScript 呼叫 JSON API。要補齊安裝、帳號、內容、商店、外掛與維運等功能時，需要決定是否換架構。

## Decision

沿用現有的 Go 伺服器與伺服器端模板，不改成前後端分離的單頁應用，也不換語言或框架。新功能在同一個執行檔內以套件劃分。

## Options rejected

原始紀錄只記下「沿用現有 Go 與模板架構」，沒有記下當時比較過的替代方案。

## Consequences

部署維持單一執行檔加 PostgreSQL。頁面不依賴前端建置工具，第三方前端套件以建置後的檔案自帶在 `web/` 下。互動較重的畫面（編輯器、後台系統頁）用原生 JavaScript 與自帶元件完成，沒有共用的前端狀態管理。
