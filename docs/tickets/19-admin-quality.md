## 已確認範圍

- 付款／商店／運送設定初次讀取會隱藏整張表單，載入完成又插入儲存列，造成位置跳動。保留實際表單佔位，載入中禁止操作，不顯示可誤用的預設值；載入狀態區與儲存列保留穩定高度，成功不再改變第一張卡片位置。失敗提示依內容正常排版，可以增高但不能遮住可編輯欄位；失敗可重試，重試及恢復後保留原有未儲存輸入。
- 移除停用 gateway 卡片整列 opacity 淡化，停用仍以既有開關與控制項狀態表達；標籤、提示、通知網址、可用複製按鈕符合 4.5:1，保留亮暗模式。
- 側欄選取項等白字品牌底目前對比不足。維持原本品牌色作裝飾，為白字實心底建立較深的同色 token，涵蓋側欄、主要按鈕、頭像及通知數字，不重新設計版面；同步 DESIGN.md 的現行後台 token 與對應設計板。
- 設定頁是跨網址導覽，改成一般具名 nav 與 aria-current，移除不相符的 tablist／tab／aria-selected；真正頁內 tab 控制不受影響。
- 頂列問題是可見快捷鍵／通知數字未完整對應名稱，不是 header 必須加名字。使用文字及提示／數字的 aria-labelledby，保留手機上可辨識的操作名稱，99+ 及目前平台快捷鍵都一致；不新增多餘 header 標籤。
- 修復文章列表 New Post、文章／頁面編輯器標題及標籤、中文固定 placeholder 在英文頁出現等確定文案問題，使用現有翻譯或新增成對繁中／英文 key。HTML 初始標題可以使用已翻譯的編輯器名稱，瀏覽器載入後依現有新增／編輯狀態顯示對應標題；共用標題欄標籤沿用既有 title 翻譯。技術名稱、範例網址及原稿不任意翻譯。
- 手機中文列表的標題欄保留至少 12rem 可閱讀寬度，長標題正常換行；沿用表格內橫向捲動，操作連結須能以觸控及鍵盤取得，整頁不橫向溢出。360／390px 以長繁中標題實測，MobileAdmin 板同步實際表格狀態。
- 共用輸入提示文字沿用不透明的 muted 色，包含編輯器空白標題；避免 70%／45% 淡化造成對比不足。既有白字品牌底的共用頭像及錯誤提示按鈕懸停也使用同一實心色，裝飾色不變。
- favicon 沿用自帶品牌 jelly-mark.svg，模板以 hash 引用，/favicon.ico 以同源暫時導向相同資源，GET／HEAD 不再 404。轉址要求重新確認，資源 hash 與位元組相符；CLI 仍完整產頁，不新增外部資源或第三方套件。
