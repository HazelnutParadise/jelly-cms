# 21 — 品牌識別位置使用同一份正式 logo

Epic：品牌一致性缺陷
User Story：使用者在頁首、側欄、頁尾及品牌識別位置看到相同的正式 Jelly CMS logo，裝飾圖案不冒充品牌標誌。
Blocked by：15、16、20 已合併。
Status：實作、局部競態回歸、瀏覽器與獨立差異審查通過；完整批次、CI 與交付的最終結果記錄於本工作單對應 PR。

## 原始素材與範圍

使用者確認 `web/admin/assets/jelly-mark.svg` 是正式 logo，SHA-256 為 `a7b81e6a34f0f354b4c3c788f59a511d43e330e9eb2a8f1bbc3a68265682b32a`，viewBox 為 85 × 100。保留整份原始位元組、五個圖形、顏色及各圖形透明度，不為深色背景改成白色、不重畫、不拉伸、不套用濾鏡或額外旋轉。

- 後台共用側欄與指令搜尋面板的品牌圖示改為引用原始 SVG，沿用既有 assetURL 內容 hash。保留連結、可辨識名稱與原本外框尺寸。
- 前台預設主題頁首與頁尾的品牌連結，改用同一份原始 SVG，取代三個 CSS 方塊；保留自訂網站名稱、主題配色、連結及既有排列。純裝飾的果凍背景、英雄區圖案、空狀態小方塊保留。
- 綠界付款跳轉頁在 internal/server/shop_payment.go 直接內嵌了另一版 logo。保留原本禁止載入圖片的 CSP，不新增圖片來源權限；這個獨立頁嵌入正式 SVG 的原始圖形，僅允許調整根節點的版面與無障礙標示。viewBox、所有子圖形、顏色、透明度及 transform 與原始素材一致，測試直接比較原始檔，不能出現第二套設計。付款表單、自動送出、網址與回傳資料不變。
- 登入頁、安裝頁與 favicon 已引用原始素材，保持原樣並納入回歸。帳號頁目前只有品牌文字，不另外新增圖示；Google／GitHub 的官方標誌與使用者頭像不變。
- 設計稿所有品牌 mark 與正式畫面一致。共用產生器 MARK、登入相關 LOGIN_MARK、Mermaid 板建置來源改用原始素材的引用；手寫板直接改，產生板只由來源重新產生。`design/project/jelly-mark.svg` 是原始檔的可攜副本，必須逐位元組相同，產生器從正式來源同步，不成為第二個設計來源。
- 不修改未安裝的第三方主題、不加入新相依套件，不變更 API、權限、資料表、文字內容或付款流程。

## 分工與驗收

- 主代理負責契約、差異審查與瀏覽器驗收，實作者不改測試；測試先保護上述品牌識別位置、原始素材與裝飾界線。
- 測試實際渲染的後台側欄／指令面板與公開頁首／頁尾，確認引用同源 hash SVG、回應內容及 hash 與正式素材一致，不再含替代的 inline SVG／CSS 三方塊；付款跳轉頁則比對內嵌圖形與正式 SVG 完全相同，且 CSP 不變。優先共用現有 HTTP fixture，不為每個外觀案例建立資料庫。
- 盤點全部設計板的品牌 mark，檢查可攜副本一致、引用可解析，沒有重新著色的 inline logo；重跑全部產生器，兩次產出相同。純裝飾不因 classname 相似而被替換。
- 瀏覽器驗證後台側欄與指令面板、前台頁首與頁尾、登入與安裝、代表性設計板，包含桌面／手機與亮／暗。確認圖片真正載入、原色原比例、無破圖及版面溢出，品牌連結與指令面板照常使用。
- CLI 繁中／英文各 21 頁仍可產生、logo 資源一併複製且 hash 正確；完整競態套件及必要 CI 通過後合併清理，不部署。
- 更新 DESIGN.md 的 logo 來源與裝飾界線，design/README.md 的設計素材同步清單包含 SVG。依既有分工於 PR 請 Claude 同步線上畫布，收到完成回報並讀回後才宣稱同步。

## 已驗證結果

- 品牌測試先在修改前重現後台兩處、前台兩處及付款 SVG 的差異。修正後主代理獨立重跑 PostgreSQL 品牌競態通過（11.180 秒），素材檢查（21.101 秒）及 CLI 競態（24.984 秒）通過；CLI 測試涵蓋繁中／英文各 21 頁與資源複製、hash。
- 81 張設計板中，69 張的 78 個品牌 mark 已替換；另有 9 張僅更新共用比例樣式，3 張不變。主代理逐板比較，除了 SVG 引用與比例保持外，其餘內容完全相同，指令面板 14 × 16 外框保持。十一支 Python 產生器及 Mermaid 建板由主代理獨立重跑，產出位元組不變；Mermaid 實際渲染後的圖表資料也不變。
- 隔離站實際驗收 1280 × 800 與 390 × 844、亮暗模式的後台側欄、指令面板、公開頁首／頁尾，以及登入頁。安裝頁在此批修改前已驗收，來源檔與素材未變。代表性 Main、Palette、ECPayHandoff、Mermaid 設計板實際顯示正確素材；未操作真實付款。
- 品牌圖片載入成功、hash 對應原始位元組、無額外濾鏡或旋轉，頁面無水平溢出。品牌連結回首頁／儀表板、手機選單及指令面板開啟／Escape 關閉正常。乾淨瀏覽器分頁的前後台主控台沒有警告或錯誤。首頁 Lighthouse 效能與無障礙均 100 分。
- gofmt、vet、原生／Windows amd64／macOS amd64 編譯及獨立 NATS 競態通過。完整 PostgreSQL／Redis 批次、CI 與合併證據以對應 PR 的最終紀錄為準，不以局部結果代替。
